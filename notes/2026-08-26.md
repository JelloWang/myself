## 📰 今日值得关注

### 1. **AgentCore 推出持久计算：多个 AI 智能体"同住"一台 EC2**
这解决了 Agent 应用落地的核心痛点——成本和资源隔离。让多个智能体共享基础设施但保持独立状态，对于需要部署大量 Agent 的企业场景（客服、运营自动化）意义重大，直接降低了 TCO。

### 2. **亚马逊云科技开源 Dogwood：给 AI 智能体的工具调用立规矩**
Agent 最大的风险就是"失控"——工具调用权限管理混乱。Dogwood 提供声明式的安全策略框架，这是 Agent 从实验走向生产的必经之路，尤其对金融、医疗等强合规行业是刚需。

### 3. **DynamoDB 原生支持 AI 搜索：向量数据库要被取代？**
并不是替代，而是降低技术栈复杂度。对于已经在用 DynamoDB 的团队，不需要再引入 Pinecone/Weaviate，直接在现有数据库上做语义检索，减少了数据同步和运维负担。适合中小规模 RAG 应用快速上线。

### 4. **Cloudflare 推出 Agent Tracing：支持截断限制**
可观测性是 Agent 生产化的"最后一公里"。Agent 的多步推理链路长、成本高，没有精细化的 tracing 就无法优化。Cloudflare 这个工具让开发者能看清每一步的 token 消耗和决策路径，对控制成本和调试至关重要。

### 5. **完全相信 AI 代码的 Uncle Bob，坦诚这条路还没走通**
来自软件工程大师的真实反馈：AI 生成代码在小场景有效，但复杂系统的架构决策、长期可维护性上仍需人类把关。这提醒 FDE 们，AI Coding 不是银弹，要建立"人机协同"的工作流，而不是盲目信任。
